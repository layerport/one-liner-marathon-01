## What it does

`main.py` (Python 3.13 standard library only) writes one original one-line
comedy joke to `/output/entry.txt`. The joke:

> I built an AI to replace me at work, and it did — it just asked HR for my desk and a raise.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
